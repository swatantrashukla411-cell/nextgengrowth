02 Full Tech Stack Architecture (Current Platform)

Frontend Layer Client Side
  • Framework: React 18.3 (Component-driven SPA)
  • Build Tool: Vite 5.2 (Ultra-fast HMR & bundling)
  • Routing: React Router DOM v6.22
  • Icons & Graphics: Lucide React (Modern, light iconography)
  • Animations: Framer Motion 12 + GSAP 3.15
  • Smooth Scroll Engine: Lenis Smooth Scroll 1.3
  • 3D Visual Elements: Three.js 0.184 (Interactive 3D canvas)
  • State & Context: React AuthContext + Custom Hooks
Backend & API Engine Server Side
  • Runtime: Node.js (v18+)
  • Web Framework: Express.js 4.22
  • Authentication: JWT (JSON Web Tokens) + Bcryptjs
  • OAuth 2.0 Integration: Passport.js + Google OAuth 2.0
  • Session & Security: Express-Session, Express-Rate-Limit
  • CORS & Security: CORS origin protection, Dotenv config
Database & Persistence Data Layer
  • Primary Database: MongoDB Atlas (NoSQL Document Store)
  • Object Data Modeling (ODM): Mongoose 8.2
  • Core Schemas: User (Students & Brands), Projects, Applications, Workspaces, KYC Credentials, Ambassador Leads
  • Data Security: Password hashing, Encrypted Tokens
AI, Payments & Integrations Services
  • AI Engine: Google Gemini AI (@google/generative-ai) for AI brief generator & talent matching
  • Payment Escrow: Razorpay Node.js SDK 2.9 (Order creation & Webhook validation)
  • Email & Outreach: Resend API 6.9 + Nodemailer 9.0
  • Utilities: ExcelJS, QRCode generation, Playwright E2E

03 Recommendations for New Campus Marketing Landing Page

क्योंकि नया Landing Page मुख्य रूप से Campus Marketing & Student Ambassador Acquisition के लिए है, इसलिए इसे निम्नलिखित मापदंडों (Criteria) पर पूरा उतरना चाहिए:

⭐ Recommended Tech Stack Approach for Team

Option 1 (Best Choice for Speed & Existing Component Reuse): React 18 + Vite + Tailwind CSS + Framer Motion + Lenis
यह NextGenGrowth के मौजूदा Client codebase के साथ 100% compatible है। Team existing Navbar, Footer, Auroras, Hero Sections और Modals को आसानी से reuse कर सकती है।

Option 2 (Alternative if SEO & Pure Static Performance is Highest Priority): Astro 4.0 or Next.js 14 (App Router)
अगर टीम Static Site Generation (SSG), 99+ Lighthouse performance score और zero-JS initial load चाहती है तो Astro बेस्ट है।
1. UI/UX & Interactive Design
  • Dark Aurora Aesthetics: Dark theme (#0F172A) with glassmorphism cards and neon accent gradients (#3B82F6, #06B6D4).
  • Smooth Scrolling: Integrate Lenis smooth scroll for effortless scrolling experience across mobile & desktop.
  • Interactive Widgets: Include Campus Stipend/Earnings Calculator (similar to CampusCalculator.jsx) and Ambassador Ecosystem Flywheel.
2. Mobile-First Optimization
  • Mobile Priority: 85%+ students target link through Instagram/WhatsApp. Layouts must be 100% responsive.
  • Fast Loading: Use WebP image formats, font-display: swap, and lazy loading for heavy animations.
  • Clickable CTAs: Instant sticky "Apply as Ambassador" button on mobile screens.
3. API Handshake & Lead Generation
  • Direct API Hook: Connect form submissions directly to NextGenGrowth server API: POST /api/ambassadors/register or POST /api/campus/lead.
  • Auto-Response Email: Trigger instant confirmation email via Resend API upon student form submission.
  • Spam Protection: Use Cloudflare Turnstile or Google reCAPTCHA v3 on signup forms.
4. Analytics & Conversion Tracking
  • Meta Pixel & LinkedIn Insight: Track conversions for Instagram/LinkedIn ad campaigns.
  • Google Analytics 4 (GA4): Funnel tracking from Hero section click to Ambassador modal submission.
  • UTM Tracking: Pass UTM parameters (source, campus, ambassador code) into lead database.
